## 1. Для чего предназначена и что умеет? (Основное направление)

- **Сама модель (`Kimi K3`, `2.78T` всего / `~104B` активных параметров, `1M` контекст):** Крупная Mixture-of-Experts (`MoE`) модель, созданная для сложного логического анализа (`reasoning`), программирования, математики и работы с большими документами.
- **Задача движка `kimi-k3-in-c`:** Инженерный эксперимент на чистом C99 (`~176 KB` бинарник, `O_DIRECT`), показывающий, как запустить модель весом `1.56 TB` (`MXFP4`) **без GPU в `8–16 GB RAM`**, подгружая прямо с NVMe SSD только **`16` активных экспертов из `896`** и `109 GB` плотного ствола на каждый токен.

---

## 2. Работает ли для написания кода?

- **Сама модель `Kimi K3` — Да, но в этом локальном C99 disk-stream режиме — Нет (`Непригодно`):**
  1. **Катастрофически медленно:** `1 токен = ~24.2 – 32.7 секунды`. Генерация короткой `def fibonacci(n):` (`28` токенов) на `124`-ядерном сервере заняла **`~5 минут` (`299.3 сек`)**, а ответ на `500` токенов кода займёт **`~3.5–4 часа`**.
  2. **Сжигает ресурс NVMe SSD (`TBW`):** Один ответ на `500` токенов кода вызывает **`~50+ TB` чтения с SSD**, что быстро убивает распаянные диски ноутбуков.
  3. **Нет инструментов агента:** Не умеет читать/редактировать файлы репозитория или запускать тесты.

## 3. Требования к железу (`Минимум` vs `Для нормальной работы`)

| Компонент | Минимум (режим disk-stream в `kimi-k3-in-c`) | Для хорошей работы (`vLLM` / `SGLang`, `30–60+ ток/с`) |
|---|---|---|
| **GPU / VRAM** | **`0 GB`** *(100% CPU + NVMe-диск)* | **`16× NVIDIA H200` (`~2.25 TB VRAM`)** или **`8× NVIDIA B300` (`~2.30 TB VRAM`)** |
| **CPU** | **`16+ ядер`** (`AVX2` / `NEON`; замеры на `124`-ядерном EPYC) | **`64–128 ядер`** (`AMD EPYC` / `Intel Xeon`) |
| **RAM** | **`8–16 GB` свободной RAM** | **`512 GB – 1 TB` DDR5 ECC RAM** |
| **SSD (Диск)** | **`≥ 1.8 TB` свободного PCIe Gen4/Gen5 NVMe** *(`1.56 TB` веса + `109 GB` trunk)* | **`4 TB` серверный Gen5 NVMe** |
| **Реальная скорость** | **`~24.2 – 32.7 сек / токен`** (`500` токенов = `~3.5–4 часа`) | **`~30 – 60+ токенов / сек`** |

> ⚠️ **Примечание по безопасности:** Не подключайте закрытый код проекта к бесплатным сторонним `:free`-прокси ради обхода медленной локальной скорости — бесплатные эндпоинты сохраняют промпты и код для обучения.

## 4. Насколько нужна локальная альтернатива?

- **Этот локальный движок нам не нужен (`1.0/10`):** Основная разработка и архитектура у нас выполняются через флагманские облачные модели (`Claude Opus`, `Codex`, `Gemini`) за секунды и без занятия `1.8 TB` на диске.
- **Если действительно нужна 100% локальная (офлайн) модель для кода:** Вместо потокового чтения `1.8 TB` с диска используйте модели, целиком помещающиеся в `32–64 GB` единой памяти Mac через **`Ollama` или `MLX` — например `Qwen3-Coder` или `Qwen2.5-Coder-14B/32B`** (`~9–20 GB`, **`30–65 токенов/сек`**, без износа SSD).
