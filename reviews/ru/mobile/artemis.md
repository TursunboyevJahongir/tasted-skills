## 1. Что это и как работает?

> [!IMPORTANT]
> **Простыми словами (Главная задача и польза):** Умеет проверять игровые и `Canvas`-экраны по картинке (`OCR`), но **требует платный API-ключ на каждый шаг**, тратит `3–40с` на действие и работает только на Android. В обычной работе бесплатный `agent-device` намного быстрее.

Открытый (`Apache-2.0`, Python `3.12+`) мультиагентный фреймворк от Google для автономного выполнения команд на естественном языке на реальных Android-устройствах и эмуляторах (`99%+` успешных задач на бенчмарке `AndroidWorld`).

Включает 2 профиля выполнения и 4 интерфейса (`Web UI localhost:8000`, `CLI`, `MCP Server`, `Python SDK`):
- **Профиль `Flash` (`~3–5 с / шаг`):** Быстрый реактивный цикл одной модели «наблюдение -> действие».
- **Профиль `Pro` (`~15–40 с / шаг`):** Мультиагентный граф на `LangGraph` (`Planner -> Operator -> Explorer -> Checker`) с предпроверкой (`Safety Net`: XML + пиксели/OCR) и итоговым отчётом для длинных сценариев на 100+ шагов.

## 2. Сильные и слабые стороны

### Сильные стороны
- **Видит кастомные экраны без Accessibility-дерева:** Сочетает `Accessibility Helper` / `UIAutomator2` с **OCR и визуальным распознаванием (`Pixel Vision`)**, поэтому справляется с `Canvas`, Flutter и игровыми интерфейсами.
- **Автономные ночные прогоны и `pytest` SDK:** Удобный Python-клиент `ArtemisClient` для длинных межприложенческих E2E-тестов Android в CI без участия разработчика.

### Слабые стороны и скрытые расходы (Платный API / скорость / платформа)
- **💸 Использование ПЛАТНОЕ (реклама «Free & open-source» вводит в заблуждение):**
  - Бесплатен только исходный код под лицензией `Apache-2.0`, а **сама работа ARTEMIS стоит денег**.
  - Инструмент не работает за счёт вашей текущей подписки `Claude Pro/Max`, `ChatGPT` или `Antigravity`: в `.env` **обязательно нужно прописать отдельный платный API-ключ с по-токенной тарификацией** (`GEMINI_API_KEY`, `OPENAI_API_KEY`, `ANTHROPIC_API_KEY`, `OPEN_ROUTER_API_KEY` или `XAI_API_KEY`, плюс опционально платный Google Cloud Vision `OCR_API_KEY`).
  - Так как внутри крутится «агент внутри агента» (`Planner`, `Operator`, `Explorer`, `Checker`, `Video Analyzer`), отправляющий на каждом шаге скриншоты экрана (дорогие мультимодальные токены) и XML во внешний LLM API, длинные прогоны `Pro` активно расходуют баланс API (тогда как наш [**`agent-device`**](agent-device.md) требует **`$0` доплат за API** и `~100` текстовых токенов прямо внутри текущего агента).
- **Только Android (`нет iOS` и `tvOS`):** Поддержка iOS в `README.md` числится лишь в планах (`[ ] iOS Platform Expansion`) — тестировать iPhone, iPad и Apple TV нельзя.
- **В `4x–45x` медленнее в ежедневной разработке:** Один шаг занимает `3 000–5 000 ms` во `Flash` и `15 000–40 000 ms` в `Pro` (против **`888 ms`** на Android и **`197 ms`** на iOS у [`agent-device`](agent-device.md)).
- **Тяжёлый стек и нагрузка на контекст:** Глобальный MCP добавляет `5` eager-тулов (`mobile_run_task` и др.) + рекомендуемый `mcp_server/rules.md` (`13.6 KB` / `~3 400 токенов`), а связка `LangGraph + LangChain + OpenCV + FastAPI` тянет Python `.venv` размером `~1 GB+`.

## 3. Безопасность и очистка перед установкой (Санитаризация)

- **Уровень риска:** `Средний` *(расход платного API, зависимость `posthog` и автоустановка APK на телефон)*
- **Проверенные точки (`pyproject.toml`, `.env.example`, `mcp_server/`):**
  - В `pyproject.toml:66` подключён пакет телеметрии `posthog>=3.5.0`.
  - По умолчанию при первой задаче автоматически устанавливает на телефон `Artemis Accessibility Helper` APK (`ARTEMIS_HELPER_AUTO_INSTALL=true`) и блокирует гашение экрана (`ARTEMIS_KEEP_DEVICE_AWAKE=true`).
  - Команда `uv run artemis mcp --install all` прописывает глобальный MCP-сервер и `rules.md` сразу во все найденные AI IDE (`Antigravity`, `Claude Code`, `Codex`, `Cursor`).
- **Обязательные ограничения при разовом использовании для Android QA:**
  1. **Не запускать** `artemis mcp --install all` — не вешать глобальный MCP и `rules.md`, вызывая инструмент только точечно через CLI (`uv run artemis run ...`) или `pytest` SDK.
  2. Выставить жёсткий лимит расходов (`spending cap`) на платный API-ключ в `.env` (по умолчанию использовать `--profile flash`).
  3. На личных или общих тестовых устройствах задать в `.env` `ARTEMIS_HELPER_AUTO_INSTALL=false` и `ARTEMIS_KEEP_DEVICE_AWAKE=false`.

- **Наша бесплатная и быстрая ежедневная альтернатива — [**`agent-device`**](agent-device.md) (`9.5/10`, `#8` активный глобальный инструмент):**

  - **Охват и скорость:** Работает в фоне без окон сразу на `iOS`, `Android`, `tvOS` и `Android TV` за `197–888 ms` (`0` MCP-раздувания, `0` телеметрии).

## 5. В каких задачах полезно?

- **Когда использовать:** Только для нестандартных Android `Canvas` / игровых экранов без дерева доступности (где нужны OCR и пиксельное зрение) либо для автономных ночных регрессионных прогонов на 100+ шагов с выделенным бюджетом на LLM API.
- **Когда не использовать:** В повседневной кроссплатформенной разработке (`Web` / `iOS` / `Android` / `TV`), для любых задач на iOS/tvOS и там, где не нужны лишние расходы на внешний API.
