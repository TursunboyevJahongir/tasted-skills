## 1. Для чего предназначен и что умеет? (Основное направление)

> [!IMPORTANT]
> **Простыми словами (Главная задача и польза):** Очень быстрый (`170+ ток/с`, окно `1M`) и дешёвый (`$0.15 / $0.60`, в кэше `$0.015`) облачный API для бэкенда ваших продуктов: массовых чат-ботов, переводов, `OCR` документов и разбора видео *(используйте только платный Zero-Retention ключ; не отправляйте приватный код в `:free`)*.

**`MiniMax M3.1 Flash API`** — быстрый и дешёвый облачный мультимодальный (`текст + фото + видео`) API, предназначенный для массовой обработки запросов внутри бэкенда продуктов (веб-приложений, мобильных приложений и админ-панелей).

**Основные задачи:**
1. **Массовые клиентские боты и переводы:** Мгновенные ответы в чатах и суммаризация текста на скорости `170–200+ токенов/сек`.
2. **Распознавание фото, документов (`OCR`) и видео:** Чтение чеков, скриншотов, документов и коротких видео с возвратом готового `JSON` (`BabyVision: 91`).
3. **Офисная и SaaS-автоматизация:** Автозаполнение таблиц, CRM и многошаговый `tool-calling` (`Automation-Bench: 62.8%`, `BankerToolBench: 76.2%`).
4. **Большой контекст (`1,000,000` токенов):** Разбор длинных логов и пакетов документов за один запрос.

---

## 2. Работает ли для написания кода?

- **Для простых скриптов и вспомогательной автоматизации — Да; для сложной архитектуры проекта — Нет:**
  - Хорошо справляется с однофайловыми скриптами, простыми UI-прототипами, генерацией SQL/regex и конвертацией данных.
  - **Не заменяет `Opus` или `Codex` в основных coding-агентах (`Claude Code`, `Codex`):** На инженерных тестах набирает **`Terminal-Bench 4.0` = `38.1%`** *(против `51.8%` у `Claude Opus 5`)* и **`NL2Repo-Bench` = `61.2%`** *(против `75.3%` у `Opus`)* — чаще ошибается на сложной многофайловой кодовой базе.

## 3. Тарифы, Скорость и Безопасность

| Показатель | Значение |
|---|---|
| **Цена Input** | **`$0.15 / 1M токенов`** *(Cached Input: **`$0.015 / 1M`**)* |
| **Цена Output** | **`$0.60 / 1M токенов`** *(в `~25–33 раза` дешевле флагманов за `$4/$20`)* |
| **Скорость (`Throughput`)** | **`170 – 200+ токенов / сек`** |
| **Контекстное окно** | **`1,000,000 токенов`** (`текст + фото + видео`) |
| **Интеграция** | Стандартный `OpenAI` или `Anthropic` SDK (через `baseURL`) |

> ⚠️ **Примечание по безопасности:** Не отправляйте закрытый код или данные клиентов в бесплатные кредиты `MiniMax Code` и `:free`-эндпоинты (они логируются для обучения). Используйте только **платный `Zero-Data-Retention` API-ключ**.

## 4. Насколько нужно нам?

- **Для бэкенда продуктов — полезно (`5.0/10`, `👍 Хороший вариант`):** Снижает затраты на API в `25–30 раз`, когда внутри приложения нужен массовый чат-бот, распознавание чеков/фото (`OCR`), модерация или перевод.
- **Для разработки кода — не нужно:** В программировании используем наши основные флагманские модели (`Claude Opus`, `Codex`, `Gemini`).
