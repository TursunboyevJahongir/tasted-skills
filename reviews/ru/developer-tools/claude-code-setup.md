## 1. Кратко: Что это и как работает?

> [!IMPORTANT]
> **Простыми словами (Главная задача и польза):** Стартовый плагин-советчик для первичной настройки Claude Code; не нужен при готовой единой базе скиллов на `skillshare`.

Официальный read-only плагин из `anthropics/claude-plugins-official`, который сканирует стек репозитория (`package.json`, CI, фреймворки) и предлагает стартовые секции `CLAUDE.md`, хуки, субагентов и MCP-серверы (например, Playwright), ничего не меняя автоматически.

---

## 2. Почему мы не стали устанавливать?

- **Инструмент первичного онбординга:** Удобен при первом знакомстве с Claude Code с нуля, но не даёт пользы в уже выстроенной системе скиллов.
- **Привязка к одному агенту и шаблонные советы:** Ориентирован только на Claude Code и предлагает тяжёлые MCP-серверы, от которых мы осознанно отказались в пользу лёгких CLI (`agent-desktop`, `agent-device`) и единой синхронизации через [**`skillshare`**](skillshare.md).
