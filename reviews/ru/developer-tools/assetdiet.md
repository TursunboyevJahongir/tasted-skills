## 1. Кратко: Что это и как работает?

> [!IMPORTANT]
> **Простыми словами (Главная задача и польза):** Находит и сжимает тяжёлые картинки, SVG, видео и 3D-модели прямо на компьютере без загрузки в облако и с откатом в одну команду (`0` постоянного расхода токенов в простое).

Инструмент аудита и сжатия медиафайлов проекта **на 100% локально** без отправки в облако:
- **Локальные движки:** `Sharp v0.35` (`libvips` — `WebP` / `AVIF`), `SVGO 3.x` (очистка SVG), `FFmpeg` (видео) и `@gltf-transform` (`GLB`/`GLTF` 3D-ассеты).
- **Безопасная оптимизация и откат:** Ищет дубликаты по SHA-256, в режиме `safe` сжимает без смены расширений и потери качества (а в `balanced` конвертирует `.png`/`.jpg -> .webp` с обновлением импортов) и ведёт журнал с бэкапами в `.assetdiet/backups/<runId>/` для мгновенного отката (`restore`).
- **Живая проверка:** На проекте с `214` медиафайлами (`150.5 MB`) команда `audit --policy safe` за `3.6` секунды нашла `-15.55 MB (-10.3%)` экономии без потери качества в `148` файлах и `18` групп SHA-256 дубликатов.

## 2. Почему через скилл `asset-diet`, а не постоянный MCP?

- **0 лишних токенов MCP:** Постоянный MCP-сервер из 16 тулов загружал бы схему в каждый чат; [skills/asset-diet](../../../skills/asset-diet/SKILL.md) включается строго по запросу и запрещает `assetdiet setup` / `mcp`.
- **Защита Expo / React Native и Git:** По умолчанию удерживает `--policy safe`, чтобы не сломать нативные иконки `app.json` и статические `.png` `require()`, а также следит, чтобы бэкапы `.assetdiet/` не попали в коммит.

## 3. Команды On-Demand CLI

```bash
# 1. Read-only аудит без изменения файлов
npx assetdiet-mcp@0.1.4 audit . --policy safe --summary

# 2. Безопасное lossless-сжатие с атомарным бэкапом
npx assetdiet-mcp@0.1.4 optimize . --policy safe

# 3. Мгновенный побайтовый откат при необходимости
npx assetdiet-mcp@0.1.4 restore --run <runId>
```
