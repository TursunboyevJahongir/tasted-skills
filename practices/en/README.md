## 🧰 What Else Can Each Tool Do? (Additional Capabilities)

| Tool | Primary Job | Additional Capabilities (What else can it do?) | Best Paired With |
|---|---|---|---|
| [**`agent-device`**](../../reviews/en/mobile/agent-device.md) | Tap mobile UIs via `@e1` refs | 1) Run **Maestro `.yaml` E2E flows** without Java (`replay/test --maestro`); 2) **Self-heal broken E2E scripts** (`--save-script` -> `healed.ad`); 3) Export **proof videos + scene-change frame grids (`record contact-sheet`)**; 4) Drive **Apple TV (`tvOS`) & Android TV** remotes. | `simslim` + `avdslim` + `cross-platform-qa` |
| [**`simslim`**](../../reviews/en/mobile/simslim.md) | Cut iOS Simulator RAM (`2.70 -> 1.16 GB`) | 1) **Reclaim `~1.5 GB` SSD space per simulator** (`disk-clean`) without wiping installed apps or auth logins; 2) Slim **Apple TV (`tvOS`), `watchOS`, and `visionOS`** simulators; 3) Cleanly clone configured simulators (`simslim clone`). | `agent-device` + `xcrun simctl` |
| [**`avdslim`**](../../reviews/en/mobile/avdslim.md) | Cut Android AVD RAM (`4.41 -> 2.64 GB`) | 1) Replace slow CPU `SwiftShader` with native **Apple Silicon Metal GPU (`host`)**; 2) Freeze logged-in test state into a **`<1.5s` Golden Snapshot** (`avdslim snapshot`); 3) Unstick black-screen Android 16+ AVDs (`avdslim repair`). | `agent-device` + `adb` |
| [**`agent-desktop`**](../../reviews/en/developer-tools/agent-desktop.md) | Verify `Google Chrome` headlessly | 1) Automate **any macOS desktop app** (Telegram, Postman, Docker, Finder, System Settings, Menu Bar) without moving the cursor; 2) Launch Electron apps with `--cdp`; 3) Call `libagent_desktop_ffi.dylib` directly from Python/Swift/Go/Node (`agent-desktop-ffi`). | `impeccable` + `client-performance-gate` |
| [**`graphify`**](../../reviews/en/architecture/graphify.md) | `0`-token AST codebase map | 1) Graph **PDF specs, Markdown docs, architecture diagrams, and videos** alongside code; 2) Export to **Obsidian Vaults, Wikis, Neo4j, or interactive HTML**; 3) Trace shortest dependency paths (`graphify path "A" "B"`). | `grill-me` + `egm-bootstrap` |
| [**`elephant-goldfish-model`**](../../reviews/en/architecture/elephant-goldfish-model.md) | Multi-agent design review (`egm-review`) | 1) **`egm-drift-report`:** Catch doc-to-code divergence automatically; 2) **`egm-brainstorm` (TRIZ):** Resolve system contradictions without compromise; 3) **`egm-bootstrap`:** Generate verified directory `README.md` contracts across a repo. | `graphify` + `T3 Code` |
| **`watch`** (`video-analyzer`) | Summarize YouTube / video files | 1) Pinpoint exact failure timestamps & frames in **QA bug-report screen recordings**; 2) Extract **`5fps` animation frames** to clone motion physics into code; 3) Catch split-second disclaimers (`SELF-REPORTED`, paid `.env` keys) in social demos. | `diagnosing-bugs` + `animate-expo` + `tasted-skills` |
| **`figma`** skill suite | Implement Figma designs in code | **Reverse direction (`Code -> Figma`):** Push existing coded pages into Figma auto-layout screens (`figma-generate-design`) and generate Figma Variables & Component Libraries from code tokens (`figma-generate-library`). | `impeccable` + `asset-diet` |
