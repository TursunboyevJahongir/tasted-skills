## 🧰 Что ещё умеет каждый инструмент? (Карта скрытых и вторичных возможностей)

| Инструмент | Основная задача | Для чего ещё можно использовать? (Дополнительные / Нестандартные возможности) | Лучшие напарники (`С чем сочетать`) |
|---|---|---|---|
| [**`agent-device`**](../../reviews/ru/mobile/agent-device.md) | Управление мобильным UI через `@e1` | 1) Запуск **Maestro `.yaml` E2E-тестов** без Java (`replay/test --maestro`); 2) **Самолечение упавших тестов** (`--save-script` -> `healed.ad`); 3) Снятие **видео + сетки ключевых кадров (`record contact-sheet`)**; 4) Пульт для **Apple TV (`tvOS`) и Android TV**. | `simslim` + `avdslim` + `cross-platform-qa` |
| [**`simslim`**](../../reviews/ru/mobile/simslim.md) | Сжатие RAM iOS Simulator (`2.70 -> 1.16 GB`) | 1) **Безопасная очистка `~1.5 GB` SSD на симуляторе** (`disk-clean`) без удаления приложений и токенов входа; 2) Облегчение симуляторов **Apple TV (`tvOS`), `watchOS` и `visionOS`**; 3) Чистое клонирование настроенного симулятора (`simslim clone`). | `agent-device` + `xcrun simctl` |
| [**`avdslim`**](../../reviews/ru/mobile/avdslim.md) | Сжатие RAM Android AVD (`4.41 -> 2.64 GB`) | 1) Переключение медленного CPU `SwiftShader` на **Apple Silicon Metal GPU (`host`)**; 2) Сохранение залогиненного тестового состояния в **`<1.5s` Golden Snapshot** (`avdslim snapshot`); 3) Починка зависших на чёрном экране AVD Android 16+ (`avdslim repair`). | `agent-device` + `adb` |
| [**`agent-desktop`**](../../reviews/ru/developer-tools/agent-desktop.md) | Фоновая проверка `Google Chrome` | 1) Автоматизация **любых десктопных программ macOS** (Telegram, Postman, Docker, Finder, System Settings, Menu Bar) без движения мыши; 2) Запуск Electron с `--cdp`; 3) Прямой вызов `libagent_desktop_ffi.dylib` из Python/Swift/Go/Node (`agent-desktop-ffi`). | `impeccable` + `client-performance-gate` |
| [**`graphify`**](../../reviews/ru/architecture/graphify.md) | AST-карта кода за `0` токенов | 1) Связывание **PDF-ТЗ, Markdown-доков, схем-картинок и видео** в единый граф с кодом; 2) Экспорт в **Obsidian Vault, Wiki, Neo4j или интерактивный HTML**; 3) Поиск кратчайшей цепочки связей (`graphify path "A" "B"`). | `grill-me` + `egm-bootstrap` |
| [**`elephant-goldfish-model`**](../../reviews/ru/architecture/elephant-goldfish-model.md) | Архитектурное ревью (`egm-review`) | 1) **`egm-drift-report`:** Авто-поиск расхождений между документацией и реальным кодом; 2) **`egm-brainstorm` (ТРИЗ):** Устранение технических противоречий без компромиссов; 3) **`egm-bootstrap`:** Генерация модульных контрактов `README.md` по всему репозиторию. | `graphify` + `T3 Code` |
| **`watch`** (`video-analyzer`) | Конспект YouTube и видеофайлов | 1) Точный поиск секунды и кадра ошибки в **клиентских видео-багрепортах**; 2) Нарезка **анимаций по `5fps`** для переноса физики движения в код; 3) Поиск скрытых плашек (`SELF-REPORTED`, платные `.env`) в рекламных роликах. | `diagnosing-bugs` + `animate-expo` + `tasted-skills` |
| **Набор `figma`** | Вёрстка кода по макету Figma | **Обратное направление (`Код -> Figma`):** Отрисовка готовых экранов из кода обратно в Figma (`figma-generate-design`) и сборка Figma Variables + библиотеки компонентов из токенов кода (`figma-generate-library`). | `impeccable` + `asset-diet` |
