## 🧰 Qaysi vositani yana nimalarga ishlatish mumkin? (Qo'shimcha imkoniyatlari)

|---|---|---|---|
| [**`agent-device`**](../reviews/mobile/agent-device.md) | Mobil ekranni `@e1` ref bilan bosish | 1) **Maestro `.yaml` E2E testlarni** Java'siz yurgizish (`replay/test --maestro`); 2) Sinib qolgan testni **o'zi davolashi** (`--save-script` -> `healed.ad`); 3) Ko'rinmas testdan **video + o'zgargan kadrlar jadvali (`record contact-sheet`)** olish; 4) **Apple TV (`tvOS`) va Android TV** pultini boshqarish. | `simslim` + `avdslim` + `cross-platform-qa` |
| [**`simslim`**](../reviews/mobile/simslim.md) | iOS Simulator RAM'ni `2.70 -> 1.16 GB` qilish | 1) **SSD disk to'lganda** o'rnatilgan ilova va login tokenlarni o'chirmasdan `~1.5 GB` log/keshni tozalash (`disk-clean`); 2) **Apple TV (`tvOS`), `watchOS` va `visionOS`** simulyatorlarini yengillashtirish; 3) Simulyatorni barcha login/ilovalari bilan toza klonlash (`simslim clone`). | `agent-device` + `xcrun simctl` |
| [**`avdslim`**](../reviews/mobile/avdslim.md) | Android AVD RAM'ni `4.41 -> 2.64 GB` qilish | 1) CPU `SwiftShader` o'rniga **Apple Silicon Metal GPU (`host`)** ni yoqib Mapbox/animatsiyalarni tezlashtirish; 2) Login qilingan tayyor test holatini **`<1.5s` da yonadigan Golden Snapshot** qilib muhrlash (`avdslim snapshot`); 3) Qora ekranda qotgan Android 16+ AVD'ni tuzatish (`avdslim repair`). | `agent-device` + `adb` |
| [**`agent-desktop`**](../reviews/developer-tools/agent-desktop.md) | `Google Chrome` ni fonda tekshirish | 1) Har qanday **macOS desktop dasturni** (Telegram, Postman, Docker, Finder, System Settings, Menu Bar) kursorni qimirlatmasdan boshqarish; 2) Electron dasturlarni `--cdp` bilan ochish; 3) Python/Swift/Go/Node'dan **`libagent_desktop_ffi.dylib`** orqali CLI'siz to'g'ridan-to'g'ri chaqirish. | `impeccable` + `client-performance-gate` |
| [**`graphify`**](../reviews/architecture/graphify.md) | Kod bazasi AST xaritasi (`0` token) | 1) Koddan tashqari **PDF ТЗ, Markdown hujjatlar, sxema rasmlari va videolarni** bitta grafga ulash; 2) Grafni **Obsidian Vault, Wiki, Neo4j yoki interaktiv HTML** ga eksport qilish; 3) Ikki modul orasidagi eng qisqa zanjirni topish (`graphify path "A" "B"`). | `grill-me` + `egm-bootstrap` |
| [**`elephant-goldfish-model`**](../reviews/architecture/elephant-goldfish-model.md) | Arxitektura dizaynini tekshirish (`egm-review`) | 1) **`egm-drift-report`:** Hujjat (`README`/`DESIGN.md`) va real kod o'rtasidagi farqlarni avtomatik tutish; 2) **`egm-brainstorm` (TRIZ):** Yechimsiz ko'ringan texnik ziddiyatlarni kompromissiz yechish; 3) **`egm-bootstrap`:** Hujjatsiz repoga modul shartnomalarini yozib chiqish. | `graphify` + `T3 Code` |
| **`watch`** (`video-analyzer`) | YouTube / video xulosalash | 1) Mijoz yuborgan **ekran yozuvi (bug-video)** dan xato sekundini va kadrini topish; 2) Boshqa ilova **animatsiyasini `5fps` kadrlarga yoyib** kodga ko'chirish; 3) Video-reklamalardagi yashirin `SELF-REPORTED` yoki pullik `.env` yozuvlarini tutish. | `diagnosing-bugs` + `animate-expo` + `tasted-skills` |
| **`figma`** skilllar to'plami | Figma dizayndan kod yozish | **Teskari yo'nalish (`Kod -> Figma`):** Tayyor yozilgan koddan Figma'ga ekran chizish (`figma-generate-design`) va kod tokenlaridan Figma Variable + Component Library (`figma-generate-library`) generatsiya qilish. | `impeccable` + `asset-diet` |
